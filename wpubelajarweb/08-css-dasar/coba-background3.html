Belajar CSS Selector: 3

Apa itu selector?

Selector adalah pola yang dipakai CSS untuk memilih elemen HTML yang ingin diberi gaya. Aturan CSS terdiri dari selector dan deklarasi di dalam kurung kurawal.

selector {
    properti: nilai;
}

1. Selector elemen

Selector elemen memilih semua elemen HTML dengan nama tag yang sama. Contoh ini membuat semua paragraf di kotak menjadi biru.

p {
    color: #1769aa;
}

Paragraf ini ikut dipilih oleh selector p.

2. Universal selector

Tanda bintang (*) memilih semua elemen. Biasanya dipakai untuk aturan umum, misalnya menghitung ukuran kotak dengan lebih mudah.

* {
    box-sizing: border-box;
}
