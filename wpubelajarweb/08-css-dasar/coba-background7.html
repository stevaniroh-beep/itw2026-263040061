Belajar CSS Selector: 7

1. Pseudo-class untuk keadaan elemen

Pseudo-class memilih elemen berdasarkan keadaan atau posisinya. Contohnya :hover saat pointer berada di atas tautan dan :focus-visible saat elemen mendapat fokus keyboard.

Arahkan atau fokuskan saya 
.tombol:hover {
    background: #0f4775;
}

.tombol:focus-visible {
    outline: 3px solid #f59e0b;
}

2. Pseudo-class berdasarkan posisi

:first-child memilih anak pertama, sedangkan :nth-child(even) memilih anak pada urutan genap.

  • Item pertama
  • Item kedua
  • Item ketiga
  • Item keempat
.daftar li:first-child {
    font-weight: bold;
}

.daftar li:nth-child(even) {
    background: #e3f2fd;
}

3. Specificity secara singkat

Jika beberapa aturan memilih elemen yang sama, browser mempertimbangkan specificity. Secara umum, selector ID lebih spesifik daripada class, dan class lebih spesifik daripada selector elemen. Jika tingkatnya sama, aturan yang ditulis belakangan biasanya menang.

p { color: navy; }          /* elemen */
.pesan { color: green; }   /* class: lebih spesifik */
#utama { color: red; }     /* ID: lebih spesifik lagi */

Ringkasan materi

Selector elemen, universal, class, ID, grup, keturunan, anak, atribut, saudara, dan pseudo-class membantu memilih elemen secara tepat. Gunakan selector sesederhana mungkin agar CSS mudah dibaca.
