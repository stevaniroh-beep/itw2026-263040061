Belajar CSS Selector: 5

1. Selector grup

Pisahkan beberapa selector dengan koma untuk memberi aturan yang sama pada elemen-elemen berbeda.

h2, .catatan {
    text-decoration: underline;
}

Teks ini memakai gaya class catatan.

2. Selector keturunan

Spasi memilih elemen yang berada di dalam elemen lain, pada tingkat keturunan mana pun.

/* Memilih semua p di dalam .demo */
.demo p {
    color: #1769aa;
}

Paragraf bersarang ini juga dipilih oleh .demo p.

3. Selector anak langsung

Tanda > hanya memilih anak langsung, bukan elemen yang lebih dalam.

/* Hanya p yang langsung berada di dalam .demo */
.demo > p {
    font-weight: bold;
}
