Belajar CSS Selector: 4

1. Selector class

Class dipakai untuk mengelompokkan satu atau beberapa elemen. Di CSS, nama class diawali tanda titik. Di HTML, class ditulis dengan atribut class.

/* CSS */
.penting {
    color: #1769aa;
    font-weight: bold;
}

/* HTML */
<p class="penting">Teks penting</p>

Contoh teks dengan class penting.

Class yang sama dapat dipakai pada lebih dari satu elemen.

2. Selector ID

ID digunakan untuk menandai satu elemen tertentu. Selector ID di CSS diawali tanda pagar (#).

/* CSS */
#pesan-utama {
    background: #fff7df;
}

/* HTML */
<p id="pesan-utama">Pesan utama</p>

Elemen ini dipilih oleh selector #pesan-utama.

Gunakan class jika gaya perlu diterapkan ke banyak elemen. Setiap ID sebaiknya unik dalam satu halaman.
