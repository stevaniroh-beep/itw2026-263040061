Belajar CSS Selector: 6

1. Selector atribut

Selector atribut memilih elemen berdasarkan keberadaan atau nilai atribut HTML tertentu.

/* Memilih tautan yang dibuka di tab baru */
a[target="_blank"] {
    color: #b45309;
}

Tautan dengan target="_blank"

2. Selector saudara

Judul contoh

Selector + memilih paragraf pertama yang langsung mengikuti h3.

Selector ~ memilih semua paragraf saudara setelah h3.

h3 + p { color: #1769aa; } /* saudara langsung */
h3 ~ p { border-left: 3px solid #54c6eb; } /* semua saudara berikutnya */
