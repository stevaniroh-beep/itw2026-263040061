Belajar CSS Background

Background digunakan untuk mengatur tampilan latar belakang elemen HTML. Ikuti langkah-langkah berikut dan amati contoh hasilnya.

1. Mengatur warna latar

Gunakan background-color untuk memberi warna. Warna dapat ditulis dengan nama, kode HEX, atau fungsi RGB.

Contoh: background berwarna lightblue
.kotak {
    background-color: lightblue;
}

2. Memasang gambar atau gradasi

Properti background-image menerima alamat gambar atau gradasi. Contoh di bawah memakai gradasi agar tetap tampil tanpa file gambar tambahan.

Contoh: background gradasi
/* Memakai gambar dari file */
.kotak {
    background-image: url("gambar.jpg");
}

/* Alternatif: gradasi warna */
.kotak {
    background-image: linear-gradient(135deg, #1769aa, #54c6eb);
}

3. Mengatur pengulangan, posisi, dan ukuran

background-repeat mengatur pengulangan gambar, background-position mengatur letaknya, dan background-size mengatur ukurannya. Nilai cover membuat gambar menutupi area elemen.

Contoh: pola berada di kanan bawah
.kotak {
    background-repeat: no-repeat;
    background-position: right 20px bottom 20px;
    background-size: 70px 70px;
}

Nilai umum background-size: cover, contain, atau ukuran tertentu seperti 200px 100px.

4. Membuat gradasi

Gradasi adalah latar yang berubah warna secara halus. Gunakan linear-gradient() untuk arah lurus atau radial-gradient() untuk pola melingkar.

Contoh: linear-gradient
.kotak {
    background-image: linear-gradient(120deg, #4f46e5, #06b6d4);
}

5. Menulis background secara ringkas

Properti background dapat menggabungkan warna, gambar, posisi, ukuran, dan pengulangan dalam satu deklarasi.

.kotak {
    background: lightblue url("gambar.jpg") center / cover no-repeat;
}

Mulailah dari warna sederhana, lalu tambahkan gambar atau gradasi dan atur tampilannya sesuai kebutuhan.
